Hermes

A private, single-user assistant that works inside one Google Account, on its owner's instructions.

What it is

Hermes is a desktop automation tool. It runs on its owner's own Mac and carries out tasks the owner asks for directly — adding a meeting to the calendar, triaging an inbox, pulling figures into a spreadsheet, drafting a document.

It is not a public product. There is no sign-up, no dashboard and no multi-user service. It is not distributed, and it has exactly one user: the owner of the Google Account that authorises it.

What it does with Google user data

  • Calendar (calendar) — lists and creates events on the owner's own calendar, when instructed.
  • Gmail (gmail.readonly, gmail.modify, gmail.send) — searches, labels, drafts and sends mail only on request. Nothing is sent without the owner approving that specific message.
  • Drive, Sheets, Docs (drive, spreadsheets, documents) — reads and edits the owner's own files to produce requested documents and reports.
  • Contacts (contacts.readonly) — read-only, used to resolve a name to an email address.

Access is granted through Google's standard OAuth 2.0 consent screen, scope by scope, and can be revoked by the owner at any time at myaccount.google.com/permissions.

What it never does: no advertising, no profiling, no analytics, no resale of personal data, no credit or lending determinations, and no training of generalised or third-party models on Google user data.

Where the data lives

OAuth tokens and working files stay on the owner's own machine, under owner-only file permissions. There is no remote application server holding Google user data, and nothing is shared with third parties.

Privacy

Full detail — data accessed, purpose, storage, retention and how to revoke — is in the Privacy Policy, which includes the Google API Services User Data Policy Limited Use disclosure.
