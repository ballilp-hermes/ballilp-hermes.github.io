Privacy Policy — Hermes Personal Assistant

Last updated: 13 November 2026 · Applies to the private automation tool operated on behalf of the account owner.

Hermes (“the application”) is a private, single-user automation tool that acts on the instructions of its operator. It is not a public product, is not distributed to third parties, and has one user: the owner of the Google Account that authorises it. This policy explains what Google user data the application accesses, why, and how it is handled.

1. Who operates the application

Link Point Trading (Hong Kong) Limited, Hong Kong. Contact: sales@link-point.org.

2. Google user data accessed

Only after the account owner grants consent through Google's OAuth screen, and limited to these scopes:

  • Gmail (gmail.readonly, gmail.modify, gmail.send) — to read, organise and draft or send mail when instructed.
  • Google Calendar (calendar) — to read and create calendar events when instructed.
  • Google Drive (drive) — to locate, read, upload and organise the owner's own files when instructed.
  • Google Sheets (spreadsheets) — to read and update the owner's own spreadsheets when instructed.
  • Google Docs (documents) — to create and edit the owner's own documents when instructed.
  • Google Contacts (contacts.readonly) — to resolve names to addresses when instructed. Read-only; contacts are never modified.

No other Google data is requested. The application does not request access to Google Drive data belonging to anyone other than the authorising account owner.

3. How the data is used

  • Only to carry out tasks the owner explicitly requests, at the time of the request.
  • No advertising, no profiling, no analytics, no sale or rental of data.
  • No use to determine creditworthiness or for lending purposes.
  • No use of data to train or improve generalised or third-party machine-learning models.

4. Storage and transfer

  • OAuth access and refresh tokens are stored locally on the owner's own Mac, in a file readable only by the owner's macOS user account.
  • Requested content is processed on that machine. There is no application server that stores Google user data, and no data is transferred to third parties.
  • Data leaves the machine only when a request is sent directly to Google APIs to perform the task, and, where a task requires language-model processing, to the model provider configured by the owner. Prompts are limited to what the task requires.
Limited Use disclosure. Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Retention and deletion

  • Tokens persist until the owner revokes them or the application overwrites them during re-authorisation.
  • Local working files and logs may be retained on the owner's machine for operational continuity and can be deleted at any time.
  • The owner can revoke the application's access at any moment at myaccount.google.com/permissions. Revocation takes effect immediately and stops all further access.
  • To request deletion of anything the application has stored, write to the contact address above; the request is handled by the account owner, who is also the only data subject.

6. Security

Access is protected by Google OAuth 2.0 with PKCE. Tokens are held in owner-only file permissions on a single machine, and the account is protected by two-step verification. No credentials are embedded in the application's pages or source.

7. Children

The application is not directed at children and is not used by anyone other than its single adult operator.

8. Changes

Any material change to this policy is published on this page with a new “Last updated” date. Because the application has one user, changes are also communicated to that user directly.
